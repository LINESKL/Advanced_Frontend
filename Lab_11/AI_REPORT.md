### Lab 11.2: Lists, Navigation, and Platform-Specific Code

## 1. Информация об использовании AI
- **Инструмент:** Google Gemini 
- **Дата:** 2026-04-04

## 2. Конкретные промпты

### Промпт 1:
"Как установить React Navigation Stack в проект Expo? Обязательно ли устанавливать react-native-safe-area-context?"

**Что получил:** Инструкцию по установке пакетов `@react-navigation/native` и нативного стека. ИИ объяснил, что `safe-area-context` обязателен, чтобы контент не перекрывался "челкой" iPhone или системными барами Android.

### Промпт 2:
"Почему для вывода большого списка товаров в мобильном приложении нужно использовать FlatList, а не метод .map() внутри ScrollView?"

**Что получил:** Объяснение механизма виртуализации в `FlatList`. Узнал, что `ScrollView` рендерит все элементы сразу (что убивает оперативную память телефона), а `FlatList` отрисовывает только те элементы, которые видны на экране.

### Промпт 3:
"Как сделать так, чтобы тень для кнопки работала и на iOS, и на Android? (Свойство shadowColor не работает на Android)"

**Что получил:** ИИ показал использование `Platform.select()`. Для iOS используются свойства `shadow*`, а для Android необходимо использовать свойство `elevation`.

## 3. Модификация и проверка
- **Навигация:** Обернул приложение в `NavigationContainer` и настроил переходы между `ProductListScreen` и `ProductDetailScreen`.
- **Передача данных:** Настроил типизацию для `RootStackParamList` и передал объект товара (`product`) через `route.params` на экран деталей.
- **Оптимизация:** Реализовал компонент `FlatList` с использованием `keyExtractor` и `renderItem` для списка продуктов. Добавил Pull-to-refresh.

## 4. Что узнал

- Научился использовать `Platform.select` для написания платформозависимого кода внутри одного компонента.
