## 2. Конкретные промпты

### Промпт 1:
"Объясни разницу между Jest и Vitest. Почему Vitest лучше подходит для Vite проектов?"

**Что получил:** Vitest — это современный тестовый фреймворк, созданный специально для Vite. Он использует ту же конфигурацию трансформации, что и Vite, обеспечивая мгновенный запуск тестов и HMR для тестов. Jest требует дополнительной настройки для работы с ESM и Vite.

### Промпт 2:
"Как правильно тестировать React компоненты с помощью React Testing Library? Покажи примеры запросов элементов."

**Что получил:** Иерархию запросов RTL: `getByRole` (предпочтительно) → `getByLabelText` → `getByPlaceholderText` → `getByText` → `getByTestId` (последний вариант). Примеры использования каждого метода и объяснение, почему `getByRole` наиболее семантичен.

### Промпт 3:
"В чем разница между fireEvent и userEvent в React Testing Library?"

**Что получил:** `fireEvent` — низкоуровневый API, который просто вызывает DOM события. `userEvent` — высокоуровневый API, который симулирует реальные действия пользователя (например, `type` вызывает keyDown, keyPress, keyUp для каждого символа). `userEvent` более реалистичен и предпочтителен.
