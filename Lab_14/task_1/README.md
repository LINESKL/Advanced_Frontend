## FlatList Performance Optimization Explanation

В React Native для отображения больших списков используется компонент `FlatList`, который виртуализирует элементы — рендерит только видимую часть списка, что критично для производительности.

Ключевые оптимизации в данном проекте:

1. **`getItemLayout`**: Предварительный расчет позиций элементов фиксированной высоты. Позволяет FlatList мгновенно определять, какие элементы должны быть отрендерены при скролле, без измерения каждого элемента.
2. **`keyExtractor`**: Уникальный ключ для каждого элемента. Помогает React определять, какие элементы изменились, добавились или удалились.
3. **`useCallback`**: Мемоизация функций рендеринга предотвращает их пересоздание при каждом ререндере родительского компонента.
4. **`initialNumToRender`**: Количество элементов для первоначального рендера (15). Баланс между быстрой загрузкой и заполнением экрана.
5. **`maxToRenderPerBatch`**: Количество элементов, рендерящихся за один батч при скролле (10).
6. **`windowSize`**: Размер окна рендеринга в единицах viewport (5 = 2 экрана сверху + текущий + 2 снизу).
7. **`removeClippedSubviews`**: Удаление невидимых элементов из нативной иерархии view (Android optimization).

## Описание проекта

В данном проекте реализован список из 100 контактов с применением всех ключевых оптимизаций FlatList для обеспечения плавной прокрутки и быстрого рендеринга. Приложение включает pull-to-refresh функционал для обновления данных.

Проект демонстрирует:
- Оптимизацию FlatList через `getItemLayout` для фиксированной высоты элементов.
- Использование `keyExtractor` для уникальной идентификации элементов.
- Мемоизацию рендер-функций с помощью `useCallback`.
- Настройку параметров рендеринга (`initialNumToRender`, `maxToRenderPerBatch`, `windowSize`).
- Pull-to-refresh функционал с `RefreshControl`.

## Ключевые концепции

- **FlatList Optimization**: применение всех доступных оптимизаций для плавной работы со списками.
- **getItemLayout**: предварительный расчет позиций элементов для мгновенной прокрутки.
- **Memoization**: использование `useCallback` для предотвращения лишних ререндеров.
- **Pull-to-Refresh**: стандартный паттерн обновления данных в мобильных приложениях.
- **SafeAreaView**: корректное отображение контента с учетом вырезов и закругленных углов экрана.

## Оптимизации производительности

```typescript
// Фиксированная высота элемента
const ITEM_HEIGHT = 80;

// Предварительный расчет позиций
getItemLayout={(data, index) => ({
  length: ITEM_HEIGHT,
  offset: ITEM_HEIGHT * index,
  index,
})}

// Настройки рендеринга
initialNumToRender={15}        // Начальное количество элементов
maxToRenderPerBatch={10}       // Элементов за один батч
windowSize={5}                 // Размер окна рендеринга
removeClippedSubviews={true}   // Удаление невидимых элементов
```
