### Lab 14.1: Performant Infinite List with FlatList

## 1. Информация об использовании AI 
- **Инструмент:** Google Gemini
- **Дата:** 2026-04-15

## 2. Конкретные промпты

### Промпт 1:
"Как оптимизировать FlatList в React Native для отображения более 1000 элементов без лагов? Какие пропсы отвечают за виртуализацию?"

**Что получил:** Объяснение параметров `initialNumToRender`, `windowSize`, `maxToRenderPerBatch` и `removeClippedSubviews`. Также AI посоветовал использовать `getItemLayout`, если высота элементов фиксирована, чтобы избежать лишних расчетов размеров.

### Промпт 2:
"Зачем оборачивать `renderItem` в `useCallback` и как правильно типизировать пропсы для него в TypeScript?"

**Что получил:** Код с использованием `useCallback`, чтобы функция не пересоздавалась при каждом рендере списка. Также пример типизации: `({ item }: { item: Contact })`.

### Промпт 3:
"Как добавить функцию 'Pull-to-Refresh' в FlatList и имитировать задержку загрузки данных через `setTimeout`?"

**Что получил:** Пример использования компонента `RefreshControl` и управления состоянием `refreshing` (true/false) внутри функции `onRefresh`.

## 3. Модификация и проверка
- **Оптимизация:** Реализовал `getItemLayout` с константой `ITEM_HEIGHT = 80`, что значительно ускорило скролл на эмуляторе.
- **Разделители:** Использовал `ItemSeparatorComponent` вместо добавления бордеров внутрь самого компонента карточки, чтобы структура кода была чище.
- **Типизация:** Настроил интерфейс `Contact` в отдельном файле `types.ts`, чтобы использовать его и в генераторе данных, и в компоненте списка.

## 4. Что узнал
- Понял разницу между `ScrollView` и `FlatList`: узнал, что `FlatList` рендерит только видимые элементы (виртуализация), что критично для памяти мобильных устройств.
- Узнал, как работают механизмы кэширования элементов в списке через `windowSize`.
- Научился работать с `RefreshControl` для обновления данных жестом "потянуть вниз".

### Lab 14.2: Robust Registration Flow & Form Validations

## 1. Информация об использовании AI
- **Инструмент:** Google Gemini
- **Дата:** 2026-04-16

## 2. Конкретные промпты

### Промпт 1:
"Как настроить `KeyboardAvoidingView`, чтобы он корректно работал и на iOS, и на Android? Какие значения `behavior` использовать?"

**Что получил:** Рекомендацию использовать тернарный оператор для выбора `behavior`: `'padding'` для iOS и `'height'` (или отсутствие) для Android. Также совет добавить `keyboardVerticalOffset`.

### Промпт 2:
"Напиши Regex для валидации email, который обязательно проверяет наличие домена .edu.kz."

**Что получил:** Регулярное выражение `/^[^\s@]+@[^\s@]+\.edu\.kz$/` и пример функции для мгновенной валидации при вводе текста.

### Промпт 3:
"Как сделать так, чтобы клавиатура скрывалась при нажатии на любое место экрана вне текстового поля?"

**Что получил:** Код с использованием `TouchableWithoutFeedback` и метода `Keyboard.dismiss()`, оборачивающий всю форму.

## 3. Модификация и проверка
- **Валидация:** Добавил логику блокировки кнопки "Create Account" (`disabled={...}`), если форма заполнена некорректно или есть ошибки в email.
- **UI/UX:** Настроил `returnKeyType="next"` для полей имени и почты, чтобы пользователь мог быстро переключаться между инпутами, и `secureTextEntry` для поля пароля.
- **Стили:** Добавил визуальную индикацию ошибки (красная рамка и текст), которая появляется только после начала ввода в поле email.

## 4. Что узнал
- Изучил проблему перекрытия интерфейса системной клавиатурой и способы её решения через `KeyboardAvoidingView`.
- Научился управлять состоянием формы через один объект `form` в `useState`.
- Понял, как комбинировать `ScrollView` и `KeyboardAvoidingView` для создания удобных форм на маленьких экранах.
